¿Qué procedimiento se sigue para las copias de seguridad y cada cuánto se ejecutan?

Las copias de seguridad se ejecutan cada noche a las 02:00 mediante una tarea programada que vuelca la base de datos y comprime el directorio de documentos 1. Antes de cada ejecución se comprueba el espacio libre en el volumen de destino y, si queda por debajo del 15 %, la tarea se detiene y avisa al responsable 2.

Los domingos se hace además una copia completa que se conserva cuatro semanas; el resto de días la copia es incremental 1 3. La restauración se prueba una vez al mes en un entorno aislado, siguiendo la lista de verificación del procedimiento 4.
